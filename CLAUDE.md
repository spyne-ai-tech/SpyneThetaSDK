## What this service is

SpyneThetaSDK is an iOS Swift Package that vendors a prebuilt Kotlin/Native XCFramework (THETAClient) exposing a Swift/Objective-C API for controlling Ricoh THETA 360-degree cameras: connecting to the camera, capturing photos/video, configuring camera settings, and receiving camera events. It is consumed by iOS apps (e.g. Spyne's camera-capture apps) that need programmatic control of a THETA camera over the local network.

**Domain:** 360 camera hardware SDK / client library

## Architecture

The repo is structured as a Swift Package (Sources/THETAClient, Sources/THETAClientSPM) that bundles a precompiled, multi-platform XCFramework (ios-arm64 and ios-arm64_x86_64-simulator slices) generated from a Kotlin Multiplatform project, with auto-generated Objective-C headers (class prefix THETAC...) exposing classes like ThetaRepository, BaseHttpClient, DigestAuth and EventWebSocket. Swift test code in tests/THETAClientTests exercises the generated Kotlin enums for structural invariants via XCTest. A separate, dependency-free Node.js harness in tests/integrity verifies the integrity (checksums/snapshot) of the vendored binary framework files, run via npm scripts defined in package.json. There is no application server, HTTP routing layer, or persistent datastore in this repository -- it is purely a client SDK plus its packaging/integrity tests.
