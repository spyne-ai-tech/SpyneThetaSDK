## What this service is

SpyneThetaSDK is a Swift client SDK for controlling THETA 360° cameras. It provides an object-oriented interface for iOS applications to capture photos and videos, configure camera settings, retrieve file metadata, and manage camera state over HTTP.

## Architecture

A Kotlin Multiplatform (KMP) library compiled to a native Swift framework (xcframework). The SDK wraps HTTP-based communication with THETA cameras through a repository pattern, exposing builders for various capture modes (photo, video, burst, interval, time-shift) and option management. Core classes include THETARepository for device communication, capture builders for configuring shots, and enums for camera modes and settings.

## Before you change this

- HTTP communication with camera assumes reliable network; timeout configuration via ThetaRepositoryTimeout is critical for mobile environments
- Digest authentication (THETACDigestAuth) may fail if credentials are not configured correctly; SDK should validate auth setup early
- Camera file system operations are synchronous; large file transfers or file listing on cameras with many images may block the UI thread
- Enum-based option values (ISO, shutter speed, aperture, etc.) are camera-model-dependent; not all options are available on all THETA models; the SDK does not validate against camera capabilities
- WebSocket event streaming (EventWebSocket) may silently disconnect on network interruption; callers must implement reconnection logic
- Multipart POST for file uploads (MultipartPostClient) may fail mid-transfer without clear recovery; consider implementing resume logic
- This is a Kotlin-to-Swift compiled framework; debugging native issues requires Kotlin knowledge; version mismatches between Kotlin runtime and Swift bindings could cause crashes
